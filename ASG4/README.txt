Assignment 4 - Lighting

Run with a local server, such as VS Code Live Server:
1. Open the ASG4 folder in VS Code.
2. Right-click asg4.html.
3. Click "Open with Live Server".

Controls:
- W/S or Up/Down arrows: move forward/back
- A/D: strafe left/right
- Q/E or Left/Right arrows: rotate camera
- Mouse drag on canvas: rotate camera

Features included:
- Phong lighting with ambient, diffuse, and specular
- Point light with position sliders, color sliders, and animation toggle
- Spotlight with independent on/off toggle and direction controls
- Normal visualization toggle
- Lighting on/off toggle
- Cubes with normals
- Spheres with generated normals
- OBJ model loader with embedded Shiba OBJ backup, so the dog appears even if fetch() has path issues

Version 4 fix: OBJ dog is rotated to face the default camera and scaled/placed on the center platform.
